# Sistema de Gestão Escolar (C)

Este é um sistema de gerenciamento escolar feito em C para terminal. O programa permite cadastrar, listar, atualizar e excluir alunos e professores, além de gerenciar disciplinas e matrículas.

---

## 🚀 Como Executar no VS Code

### Pré-requisitos
* **VS Code** instalado.
* Um compilador C instalado (como o **GCC/MinGW** no Windows ou `gcc` no Linux/Mac).
* Extensão **C/C++** da Microsoft instalada no VS Code.

---

## 1. Clonar o Repositório

Abra o terminal do seu computador (ou o terminal integrado do VS Code) e rode:

```bash
git clone [https://github.com/JoaoLupoxDev/Projeto-Escola-INF029.git](https://github.com/JoaoLupoxDev/Projeto-Escola-INF029.git)

Para executar o projeto, abra o ficheiro main.c no VS Code e clique no botão de Run (ou pressione F5 / Ctrl + F5) para compilar e rodar o código.
